# 라벨 규칙 (초안 v0.1)

> 도구: CVAT. 목적: 두 사람이 같은 영상을 라벨링해도 같은 결과가 나오게 하는 것.

## 1. 라벨 대상
| 라벨 | 형태 | 규칙 |
|---|---|---|
| `ball` | 바운딩 박스 | 공 윤곽에 딱 맞게. 번져 보이면 번진 전체를 감싼다 |
| `visibility` (ball 속성) | `visible` / `partial` / `occluded` | 아래 2장 |
| `home_plate` | 점 5개 (세션당 1회) | 보정 기준점. 순서 고정: 앞면 좌 → 앞면 우 → 우측 모서리 → 뒤 꼭짓점 → 좌측 모서리 |
| `pitch` (투구 단위) | 태그 | `truth`: strike / ball / unknown, `truth_source` |

## 2. 가림 표기
- `visible`: 공 전체가 보임
- `partial`: 공의 일부만 보임. 보이는 부분만 박스로 감싼다
- `occluded`: 안 보임. **박스를 그리지 않는다.** 위치를 추측해서 그리지 않는다
- 포수 미트에 들어간 뒤는 라벨링하지 않는다

## 3. 라벨 구간
- 시작: 투수 손에서 공이 떨어진 첫 프레임
- 끝: 포수 미트에 닿거나 타격되기 직전 프레임
- 전 프레임 라벨이 원칙이나, 시간이 부족하면 **홈플레이트 근처 구간부터** 채운다 (통과 지점 추정에 가장 중요)

## 4. 정답(`truth`)
- 줄 존 틀 통과 여부를 영상으로 판독한다. 판독 영상(본 카메라 / 보조 카메라)은 `truth_source`에 적는다.
- 판독이 애매하면 **`unknown`** 으로 둔다. 추측으로 strike/ball을 채우지 않는다.
- 심판 콜은 정답이 아니라 참고 정보로 별도 칸에 적는다.

## 5. 품질 확인
