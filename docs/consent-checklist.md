# 촬영 동의서·허락 항목 목록 (초안 v0.1)

> 이것은 **동의서에 들어가야 할 항목 목록**이지 법률 문서가 아닙니다.
> 실제 서식은 창업지원단 법률 상담 등 전문가 검토를 거쳐 확정합니다. 담당: 경영.

## 1. 촬영 대상자 동의서에 넣을 항목
- [ ] 촬영 주체: 팀명, 소속(한성대학교), 담당자 이름·연락처 `[__]`
- [ ] 촬영 목적: 스트라이크/볼 판정 보조 기술의 연구·개발
- [ ] 수집 내용: 경기·투구 영상 (얼굴·신체 동작 포함), 타자 신장
- [ ] 이용 범위: 내부 연구·모델 학습·정확도 검증
- [ ] 외부 공개 범위: 발표 자료·지원사업 서류·홍보 영상에 쓸지 **항목별로 따로 동의** 받기
- [ ] 제3자 제공 여부 (없으면 없다고 명시)
- [ ] 보관 기간과 파기 방법 `[__]`
- [ ] 동의 철회 방법과 연락처, 철회 시 처리 (해당 영상 삭제 등)
- [ ] 동의하지 않아도 불이익이 없다는 안내
- [ ] 대가 여부 (무상이면 무상이라고 명시)
- [ ] 미성년자가 포함될 경우 보호자 동의 (사회인야구에서도 가능성 확인)
- [ ] 날짜, 성명, 서명

## 2. 구장·리그 허락에서 확인할 것
- [ ] 촬영 허가 주체 (구장 관리자 / 리그 운영자)
- [ ] 백네트 뒤 약 3m 높이에 장비를 설치해도 되는지, 고정 방법 제한
- [ ] 촬영 가능 일시, 경기 방해 금지 조건
- [ ] 장비 사고·파손 시 책임
- [ ] 리그 소속 선수 전체에 대한 안내 방법 (공지, 현장 안내문)

## 3. 현장 운영
- [ ] 촬영 중임을 알리는 안내문 게시
- [ ] 동의하지 않은 사람이 찍혔을 때 처리 방법 (해당 구간 미사용·삭제)
- [ ] 서명된 동의서 보관 위치와 담당자 `[__]`

## 4. 전문가에게 물어볼 것
- 개인정보 관련 법령상 영상(얼굴)의 취급과 필요한 고지 항목
- 학습에 쓴 영상의 동의가 철회되면 모델은 어떻게 해야 하는지
- 앱 약관의 '참고용' 문구와 오판 책임 범위
- AI Hub 데이터 이용 약관과 우리 촬영 데이터를 함께 쓸 때의 제약
