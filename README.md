# PitchEye

사회인야구를 위한 모바일 ABS(자동 볼·스트라이크 판정) 앱입니다.

아이폰 1대를 백네트 뒤 약 3m 높이에 세워 두면, 경기 중 챌린지 요청이 들어왔을 때 그 투구가 스트라이크인지 볼인지를 신뢰도와 함께 알려줍니다.

> **개발 초기 단계입니다.** 아직 판정 기능은 없고, 정확도도 측정 전입니다.

## 무엇을 하는 앱인가

- 투구를 1080p 240fps로 계속 촬영하면서 최근 약 3초를 기기에 보관합니다.
- 챌린지 요청이 오면 그 구간에서 공을 찾아 궤적을 계산하고, 홈플레이트를 통과한 지점을 스트라이크존과 비교합니다.
- 결과는 세 가지 중 하나입니다.

| 결과 | 의미 |
|---|---|
| **STRIKE** | 스트라이크존을 통과 |
| **BALL** | 스트라이크존을 벗어남 |
| **판정 보류** | 가림·검출 부족 등으로 확신할 수 없음 |

확신이 없으면 억지로 판정하지 않고 보류를 냅니다.

**PitchEye는 참고용 도구이며, 최종 판정은 심판이 합니다.**

## 동작 방식

모든 처리는 기기 안에서 이루어집니다.

1. 캡처 — 1080p@240fps
2. 링버퍼 — 최근 약 3초 보관
3. 투구 트리거 — 포즈 인식
4. 공 검출 — 소형 CNN (Core ML)
5. 추적 — Kalman 필터
6. 궤적 피팅 — 물리 모델
7. 홈플레이트 평면 통과 지점 계산
8. 스트라이크존 계산 — 타자 신장 비율
9. 판정과 신뢰도
10. 결과 출력

## 저장소 구조

| 폴더 | 내용 |
|---|---|
| `ios/` | iOS 앱 (Swift, SwiftUI, AVFoundation, Core ML) |
| `ml/` | 공 검출·추적·궤적·존 판정 (Python, PyTorch) |
| `server/` | 서버 (예정) |
| `data/` | 영상·라벨 (원본은 저장소에 올리지 않음) |
| `docs/` | 촬영 프로토콜, 라벨 규칙, 입출력 스펙 등 |
