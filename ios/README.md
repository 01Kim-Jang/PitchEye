# PitchEye iOS

지금 앱은 1080p@240fps로 프레임을 실시간으로 받을 수 있는지 실기기에서 재는 단계입니다.
링버퍼와 판정은 아직 없습니다.

## 실행
1. `PitchEye.xcodeproj`를 Xcode로 연다.
2. Signing & Capabilities에서 Team을 본인 Apple ID로 고른다. 번들 ID가 겹치면 바꾼다. 이 변경은 커밋하지 않는다.
3. 아이폰을 연결하고 실행한다. **시뮬레이터에는 카메라가 없어 홈·안내·설정 화면만 확인할 수 있다.**

## 화면
| 화면 | 파일 | 내용 |
|---|---|---|
| 홈 | `HomeView.swift` | 촬영 시작, 촬영 설정, 사용 안내 |
| 촬영 전 안내 | `GuideView.swift` | 4단계, 건너뛰기, 다음부터 보지 않기 |
| 촬영, 결과 | `CaptureView.swift` | 미리보기, 실측 값, 시점별 기록, 결과 보내기 |
| 설정 | `SettingsView.swift` | 안내 표시, 촬영 사양, 기기 정보 |

색·버튼 모양은 `Theme.swift`, 측정 로직은 `CaptureController.swift`와 `FrameStats.swift`에 있다.

## 최소 사양 (`Requirements.swift`)
| 항목 | 값 |
|---|---|
| 해상도 | 1920×1080 |
| 프레임레이트 | 240fps |
| 링버퍼 | 최근 약 3초 (미구현) |
| OS | iOS 17.0 이상 |
| 기준 테스트 기기 | iPhone 17 |

포맷은 기종명이 아니라 해상도·fps로 고르므로, 같은 포맷을 제공하는 다른 기종에서도 그대로 동작한다.
설정 화면의 "모델 코드"는 Apple 내부 코드다. 예를 들어 `iPhone18,3`은 iPhone 17이다.

## 실기기에서 확인할 것
촬영을 끝내면 결과 화면의 "결과 보내기"로 기록을 텍스트로 내보낼 수 있다. 그 내용을 기기 모델, iOS 버전, 날짜와 함께 `docs/`에 남긴다.

- [x] 홈에 "240fps 촬영 지원 기기"로 표시되는가 (iPhone 17에서 확인)
- [ ] 촬영 중 실측 fps가 240 근처로 유지되는가
- [ ] 빠진 프레임·버려진 프레임이 얼마나 생기는가 (1분, 10분, 30분)
- [ ] 발열 상태가 언제 바뀌고, 그때 fps가 어떻게 되는가 (실내 / 야외 직사광선)
- [ ] 가로로 돌렸을 때 미리보기가 똑바로 보이고 오른쪽 숫자 칸이 잘리지 않는가
- [ ] 설정의 지원 포맷에 표시되는 화각 (백네트 뒤 구도에 충분한가)
