# PitchEye iOS — 캡처 점검 앱

1080p@240fps로 프레임을 실시간으로 받을 수 있는지 실기기에서 확인하는 최소 앱입니다.
판정·링버퍼는 아직 없습니다.

## 실행
1. `PitchEye.xcodeproj`를 Xcode로 연다.
2. Signing & Capabilities에서 Team을 본인 Apple ID로 고른다. 번들 ID가 겹치면 바꾼다.
3. 아이폰을 연결하고 실행한다. **시뮬레이터에는 카메라가 없어 사양 화면만 확인할 수 있다.**

## 최소 사양 (`Requirements.swift`)
| 항목 | 값 |
|---|---|
| 해상도 | 1920×1080 |
| 프레임레이트 | 240fps |
| 링버퍼 | 최근 약 3초 (미구현) |
| OS | iOS 17.0 이상 |
| 기준 테스트 기기 | iPhone 17 |

포맷은 기종명이 아니라 해상도·fps로 고르므로, 같은 포맷을 제공하는 Pro 이상 기종에서도 그대로 동작한다.

## 실기기에서 확인할 것
결과는 숫자 그대로 `docs/`에 기록한다 (기기 모델, iOS 버전, 날짜 포함).

- [ ] "이 기기 → 1080p@240fps"가 **지원**으로 나오는가
- [ ] 측정 시작 후 실측 fps가 240 근처로 유지되는가
- [ ] 간격 이상·드롭이 얼마나 생기는가 (1분, 10분, 30분)
- [ ] 발열 상태가 언제 바뀌고, 그때 fps가 어떻게 되는가 (실내 / 야외 직사광선)
- [ ] 고속 포맷 목록에 표시되는 화각 (백네트 뒤 설치 구도에 충분한가)
